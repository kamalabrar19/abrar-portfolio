# Portfolio design direction

Surface: Decide / Learn, with project exploration secondary.

A charcoal editorial canvas, warm white typography, acid-lime highlights, hairline separators, a pointer-responsive wireframe neural core, and large left-aligned headings. Space Grotesk for headings, Manrope for body, monospace only for labels. The composition moves from a two-column identity/3D hero into a horizontal capability strip, alternating project panels, then a quiet experience timeline and contact section.

Content authority: the supplied CV. No invented performance metrics, certifications, dates, availability claims, or LinkedIn profile. GitHub URL preserved from the existing contact component. Diagrams in project cards are explicitly conceptual, not claimed screenshots.

Interactions: active anchor navigation, accessible mobile menu, project category filters, reduced-motion toggle, and a validated email-draft form. Three.js is lazy loaded; a static CSS orb remains when WebGL is unavailable. Keyboard users have visible focus states and normal links.

Contact is deliberately local-only: preparing a message does not transmit it. Visitors then choose the email link to open their own mail app. No API credentials are embedded.
